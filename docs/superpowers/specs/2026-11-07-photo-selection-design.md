# 名人婚纱在线选片网站：本地 MVP 设计

日期：2026-11-07
状态：已确认

## 1. 目标与范围

在 `/Users/chigo.liao/Documents/爸妈摄影/claude-dev/app` 下构建一个可本地运行的单体网站：影楼工作人员可以从照片源目录导入底片、创建/管理选片任务、查看多人合并结果、锁定并导出清单；客户可以通过电脑或同一 Wi-Fi 下手机打开邀请地址，登录、多人协作选片、提交并在锁定后下载原片。

本地版不接入真实短信、云对象存储或在线支付。验证码固定为 `123456` 并打印到服务端控制台；通知写入数据库并在后台标记为“已发送（模拟）”；照片生成物保存到 `app/data/`；原始照片只读，绝不移动、重命名、删除或修改。数据不自动清理。

一期实现 MVP：项目骨架与 SQLite、照片目录导入、客户端登录/选片/大图/提交、后台任务与汇总、CSV 导出、锁定/退回、原片单张与 ZIP 下载。精修成片上传与交付保留可扩展接口或占位，不阻塞一期使用。

## 2. 关键业务规则

- 默认影楼为“名人婚纱”，水印为“名人婚纱 · 预览”，加片单价为 ¥20/张。
- 套餐演示数据：精修 20 张、30 寸相框 1 个、10 寸摆台 1 个、相册 1 本；相册固定收录全部精修，不另行选片。
- 精修选择是所有选片人的并集；仅选片角色的选择也计入并集。
- 相框/摆台必须从精修照片中指定，每个产品槽位只有一个最终值；多人设置不同时以最后一次设置为当前值，其他设置作为建议展示。
- 取消本人精修选择时清除本人对该照片的相框/摆台指定；不影响其他人的选择。
- 额度按合并结果计算。允许超选时显示超额数量和到店结算金额，不接入支付；不允许超选时达到额度后禁用新的精修选择。
- `share_selection=true` 时其他客户可看到该选片人的具体标记；关闭后其他客户看不到其标记，但影楼始终可见。未公开时客户端仍可显示合并计数中包含未公开选择。
- “选片+提交”角色必须提交；“仅选片”角色没有提交按钮但选择计入合并结果；“仅查看”只能浏览底片及可见选择。
- 所有可提交角色提交后任务进入 `submitted`；截止时间不自动锁定；影楼手动锁定，锁定后客户不能改选。
- 锁定后原片可下载，除非影楼关闭该任务的原片下载；加片费是否结算不影响原片下载。
- 本地版生成原图 ZIP 保存到 `app/data/`，记录有效期字段但不自动清理。

## 3. 技术架构

### 后端

Node.js 20+、Express、better-sqlite3、sharp、archiver、multer、bcryptjs、jsonwebtoken/cookie session。一个进程同时提供 REST API 与前端构建产物，监听 `0.0.0.0:3000`。启动时输出 localhost、局域网地址与 `/admin` 后台地址。

配置项包括 `PORT`、`PHOTO_SOURCE_DIR`、`DATA_DIR`、`DEV_OTP`。默认照片源为项目上两级目录，扫描第一层的 jpg/jpeg/png/heic 文件，跳过隐藏文件和 `claude-dev/`。

SQLite 在启动时建表并 seed：studio、staff、package_template、package_template_item、job、job_item、photo、selector、selection、slot_assignment、photo_note、retouched_photo、download_package、audit_log、notification，以及本地会话所需的验证码/会话表（如实现为内存会话则不持久化敏感登录状态）。所有写操作按 job 隔离并记录必要审计日志。

照片导入扫描照片源目录，写入 job 的 photo 记录；sharp 生成宽约 400 的缩略图和宽约 1600、带“名人婚纱 · 预览”水印的预览图，放在 `data/`。原图路径仅指向源文件或本地上传副本，不改动源文件。导入过程提供状态查询，避免页面误以为尚未完成。

### 前端

Vue 3 + Vite，使用响应式 CSS，不强制引入大型 UI 框架。视觉基调：背景 `#F6F4F0`，白色卡片、`#E6E1D9` 边框、12px 圆角；主色 `#7A4E31`，辅色 `#2E6460`，警示 `#A33A1E` / `#FBEDE8`；系统字体优先 PingFang SC，标题回退 Noto Serif SC。所有交互控件有清晰焦点态，触控区域至少 44px。

路由分为客户区 `/c/...` 与后台 `/admin/...`。客户工作台桌面端为左侧额度栏 + 右侧照片网格，手机端额度栏变为顶部三格、照片三列；大图查看使用深色背景、左右导航、键盘左右键和空格快捷操作；确认页集中处理超额、产品冲突、提交状态。后台使用任务列表、任务详情、导入/创建表单、选片人管理和汇总表。

客户端每次选择、取消、槽位指定、备注或公开设置修改立即请求 API 并刷新必要状态；10 秒轮询任务变更。请求失败时保留当前操作到浏览器本地暂存并显示提示，恢复后重试。预览图阶段禁用右键仅作为尽力而为的 UI 防护，不视为安全边界。

## 4. API 与权限边界

客户端提供登录、任务详情、照片分页/筛选、精修选择增删、产品槽位指定、备注、公开设置、确认数据、提交/撤回、下载列表、单张下载和 ZIP 生成/下载接口。后台提供任务列表/创建/修改、照片导入、套餐产品和选片人管理、邀请/模拟通知、汇总、提醒、锁定/退回、CSV 导出、结算标记和原片下载配置接口。

所有客户端接口从会话中取得 selector 身份，不接受客户端自行指定 selector_id；所有照片和产品必须属于当前 job。锁定后所有变更接口返回明确错误。后台接口要求 staff 会话；后台始终可读取未公开选择。下载接口再次校验任务、角色、任务状态和 `allow_original_download`，不直接暴露文件系统路径。文件名和压缩包条目使用安全 basename，避免路径穿越。

本地登录使用邀请 token + 手机号 + 固定开发验证码。管理员演示账号为 `admin` / `13800000000` / `admin123`。默认演示任务包含小雅、阿杰、妈妈及照片源目录全部照片。

## 5. 页面和核心交互

### 客户

- 登录页：手机号、验证码、邀请任务入口；显示开发版验证码提示。
- 选片工作台：照片卡片展示缩略图、本人精修状态、相框/摆台标签、公开他人标记；筛选全部/我已选/未选/相框摆台/某人选择；显示合并额度、超额金额、选片人状态和公开开关。
- 大图页：预览水印、前后切换、缩略图条、可见选择人、照片备注；空格切换本人精修选择。
- 提交确认页：合并结果、产品槽位、冲突、多人对比、超额接受二次确认；提交角色支持提交与截止前撤回。
- 我的照片：锁定后的原片单张下载和生成 ZIP；精修成片区显示未交付状态。

### 后台

- 任务列表：状态、截止时间、提交进度、超期提示。
- 新建任务：标题、截止时间、套餐、超额规则、原片下载开关、选片人；支持从照片源目录导入和网页上传到 data/uploads。
- 任务详情：导入进度、选片人卡片、公开状态、并集数量、相框/摆台建议与最终值、客户备注、加片数量/金额、锁定/退回、模拟提醒。
- 导出：CSV 至少包含照片原文件名、合并用途、每位选片人的选择状态、相框/摆台、客户备注。

## 6. 错误处理与验收

API 使用统一 JSON 错误结构与合适 HTTP 状态码：400 参数错误、401 未登录、403 无权限、404 不存在、409 状态冲突、500 服务错误；前端展示可理解的中文提示。导入失败单张不应阻塞其余照片，并在后台显示失败项。

验收重点：首次启动能看到全部 63 张照片且预览有水印；两个会话的公开选择在约 10 秒内同步；合并额度与超额准确；相框/摆台只能来自精修且取消精修会清除本人指定；仅选片角色不能提交但计入后台；全部提交状态正确；后台能看到未公开选择、导出并锁定；锁定后客户不能改但能下载无水印原片；原始照片大小和修改时间不变。

测试重点包括数据库业务规则单元测试、API 权限/状态测试、照片导入与水印测试、CSV/ZIP 生成测试，以及至少一个客户端/后台关键流程的浏览器级冒烟检查。运行命令遵循 `npm install`、`npm run dev`、`npm run build && npm start`、`npm run reset`。

## 7. 明确不做的内容

本地 MVP 不接真实短信、在线支付、云对象存储、WebSocket、自动数据清理和微信小程序。精修成片上传与交付作为二期扩展，不影响锁定后原片下载和一期选片闭环。
