# studio-photo-picker · 名人婚纱在线选片

影楼在线选片系统：影楼上传底片、配置套餐（如 20 张精修 + 30 寸相框 + 10 寸摆台 + 相册），客户（可多人、异地）在电脑或手机上选精修、指定相框/摆台、评论讨论，影楼汇总、锁定并导出修图清单，客户可下载原片。

## 目录

| 路径 | 内容 |
|---|---|
| `app/` | 网站代码（Node.js + Express + SQLite + Vue 3），启动方式见 `app/README.md` |
| `design/` | 设计稿源码（6 个页面，参考用） |
| `影楼选片网站-需求与数据结构.md` | 需求、业务规则、数据结构、接口 |
| `本地开发说明.md` | 本地部署版约定 |
| `修复与改进方案-v1.md` | 第一轮修复方案与验收清单 |
| `审查意见与修复方案-v2.md` | 第二轮审查、手机适配、数据持久化（当前优先级最高） |

## 注意

- 原始照片放在仓库外的上一级目录，只读，不会被提交。
- `data/`（数据库、缩略图、备份）含客户信息，已在 `.gitignore` 中排除，不要提交。
