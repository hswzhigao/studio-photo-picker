# 名人婚纱 · 在线选片（本地版）

本地可运行的多人协作在线选片站点：客户可以在手机或电脑上选择精修照片、指定相框/摆台，并按权限查看其他选片人的公开选择；影楼后台可以看到所有人的选择、导出汇总并锁定任务。

## 启动

```bash
cd "/Users/chigo.liao/Documents/爸妈摄影/claude-dev/app"
npm install
npm run dev
```

启动后优先使用局域网地址：

- 电脑/手机：<http://192.168.31.22:3000>
- 影楼后台：<http://192.168.31.22:3000/admin>

如果电脑的 `localhost:3000` 被其他本地服务占用，请不要使用 localhost；以启动日志打印的“手机访问地址”为准。手机需要和电脑连接同一个 Wi‑Fi。局域网 IP 变化时，以启动日志中的新地址为准。

## 初始账号

首次启动时，seed 会创建一名管理员和示例客户。初始密码必须通过环境变量注入：

- `INITIAL_STAFF_PASSWORD`：管理员初始密码
- `INITIAL_CUSTOMER_PASSWORD`：示例客户初始密码

未配置时应用为账号生成随机初始密码并强制首次登录改密；密码不会写入日志或页面。管理员手机号为部署时创建的账号手机号，客户和选片人手机号以数据库为准。正式部署请通过安全的环境配置注入密码，不要把密码写进 README、命令参数或代码。

客户页面的“公开选择”开关只影响其他客户的可见性，影楼后台始终可见。

## 主要流程

1. 管理员登录后，首次必须修改密码；后台可创建/停用/重置客户账号，管理员可管理员工账号。
2. 客户登录后点击照片右上角勾选精修；选择会自动保存。
3. 相框、摆台只能从本人精修照片中指定，并会自动计入本人精修。
4. 选片人可以提交；超出套餐额度时按 `¥20/张` 标记，到店结算。
5. 影楼进入 `/admin`，登录后查看所有选片人的汇总，确认后锁定任务；后台可执行导入、提醒、结算、通知和日志查询。
6. 锁定后客户只读；若任务允许原片下载，客户可以在页面底部生成并下载原片 ZIP。

原片下载以“任务已锁定”和后台开关为前置条件；应用不会在锁定前提供原片，也不会把服务器绝对路径返回给浏览器。

## 线上验收规范

- 线上验收只能使用**专门创建的测试订单**和测试客户账号，不得对真实客户订单执行选片、评论、锁定、导出或清理以外的验收操作。
- 测试密码只通过后台一次性登录信息卡交付，不写入本地文件、命令参数、提交记录或截图。
- 验收产生的评论、备注、导出包、通知、审计和变更记录必须在验收后清理，并逐项列出。
- 真实订单只做只读核对；任何写操作必须先得到明确授权。

## 服务器字体与预览图

预览图水印使用中文字体渲染。Linux 服务器必须安装 `fonts-noto-cjk`，否则水印会显示为方框/乱码：

```bash
sudo apt-get install -y fonts-noto-cjk
```

修改水印代码或更换服务器字体后，重建全部预览图（不会修改原图）：

```bash
DATA_DIR=/srv/studio-photo-picker/data npm run regenerate-previews
```

## 数据与原片安全

- 应用数据库、缩略图、预览图和 ZIP 文件只写入 `data/`。
- 原始照片扫描项目上一级目录第一层；原始照片本身只读，导入过程只生成 `data/thumbnails/` 和 `data/previews/` 中的派生文件。
- 原始照片不会被应用修改；过期下载包会由后台定期清理。
- 当前登录使用密码认证；正式部署请通过环境变量安全注入初始密码，不要使用演示凭据。

## 数据库迁移

应用启动时会自动执行 `src/db/migrations/` 下尚未执行的迁移，并在 `schema_migrations` 中记录版本；已有 `data/app.sqlite` 会被识别为已执行 `001`，不会删除或重建现有数据。当前迁移也会为通知读标记建索引。迁移失败会阻止应用继续启动。

如需运行测试，测试使用真正的 SQLite 内存库 `:memory:`，不会在项目目录生成数据库文件。
