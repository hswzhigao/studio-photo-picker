| Lightbox.html | 客户 · 大图查看 | F3 |

## 怎么读

- **不能直接用浏览器打开**：它们是设计工具的组件格式，依赖画布运行时（`support.js`），本地打开会是空白或不完整。请把它们当作**参考源码**阅读，在 `app/` 里用 Vue 重新实现。
- 结构：`<x-dc>` 里是页面 HTML，样式全部写在行内 `style` 里，可直接照抄颜色、间距、圆角、字号。
- `{{xxx}}` 是数据占位，值来自文件底部 `<script>` 里 `renderVals()` 返回的对象。
- `<sc-for list="{{items}}" as="p">` = 循环（相当于 Vue 的 `v-for`）；`<sc-if value="{{cond}}">` = 条件渲染（相当于 `v-if`）。
- `onClick="{{fn}}"` = 点击事件。
- `Main.html` 底部的脚本包含选片的前端逻辑示例：选/取消精修、设相框/摆台（取消精修时一起清除）、筛选、额度和超额计算、公开开关。
- 页面里的照片是色块占位，开发时换成真实缩略图；人名、数量等是演示数据。
- 页面之间的 `<a href="Review.dc.html">` 表示跳转关系（选片 → 确认，选片 → 大图）。
